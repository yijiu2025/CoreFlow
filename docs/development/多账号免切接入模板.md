# 多账号免切接入模板

> 抖音式多账号免密切换的前端实现模板。新应用（Vue 3 + Pinia + TypeScript）按本文复制 4 个文件即可接入。
> 后端能力已就绪，前端无需新增后端接口。

---

## 1. 什么是多账号免切

用户在浏览器登录过多个账号（勾选"记住我"）后，下次打开应用直接显示账号列表，点一下就切过去，不用再输密码。和抖音/微博的账号切换体验一致。

### 核心概念：accountKey 与 cookie 名分离

| 角色 | 值 | 说明 |
| --- | --- | --- |
| `accountKey`（前端持有） | uid 明文，形如 `d102d02f-c338-4847-8cd8-71afb69b878a` | localStorage key + 切账号发送值，**身份标识非凭证** |
| 凭证 cookie 名（后端派生） | `HMAC-SHA256(uid, SESSION_SECRET)` 前 16 hex，形如 `k_a827ee221c2d47f3` | HttpOnly cookie 名，后端 `accountKeyForUid(uid)` 派生，**JS 读不到** |

后端从 accountKey 派生 cookie 名：`cookieName = HMAC(uid, SECRET)`，无需解密（HMAC 单向，后端有 SECRET 可算）。

**特性**：
- **确定性去重**：同 uid → 同 HMAC → 同 cookie 名，localStorage 以 uid 为 key 天然去重
- **accountKey ≠ cookie 名**：accountKey 是 uid 明文，cookie 名是 HMAC(uid)，两者分离
- **uid 是公开标识**（= JWT `sub`），非凭证；真正凭证 refreshToken 全程在 HttpOnly cookie
- **随 SECRET 变化**：换 `SESSION_SECRET` → HMAC(uid) 变 → 旧 cookie 读不到 → 强制重新登录

## 2. 整体架构

### Cookie 模型

| Cookie | HttpOnly | 作用域 | 内容 | 谁写 | 谁读 |
| --- | --- | --- | --- | --- | --- |
| `sid` | ✅ | `/` 全站 | HMAC 签名的 sessionId（短期 30min / 长期 30d） | 后端 createSession | 后端每请求验证 |
| `sid_r` | ✅ | `/auth/v1/refresh-session` 收窄 | refreshToken（30d，仅刷新端点携带） | 后端 createSession | 后端刷新时 |
| `k_<HMAC(uid)>` | ✅ | `/` | 某账号的 refreshToken（180d，记住我账号才有） | 后端 bind-session（cookie 名=HMAC(uid)） | 后端 switch-account（用 accountKey=uid 派生） |
| localStorage `saved_accounts` | ❌（前端） | — | `{[accountKey]: {username, avatar}}`，仅展示 | 前端 addSavedAccount | 前端 LoginModal |

**关键点**：真正的免切凭据是 HttpOnly cookie `k_<HMAC(uid)>`，JS 读不到（防 XSS 窃凭证）。localStorage 只存 accountKey(=uid) + 展示信息，不含任何凭证。

### 登录流程

```
用户点登录 → LoginModal 打开
  ├─ 有 savedAccounts（localStorage）→ 模式 A：账号列表
  └─ 无 → 模式 B：iframe 加载 oauth21 登录页

[iframe 登录成功]
  oauth21 postMessage({type:'LOGIN_SUCCESS', token, sessionToken, user}) → 父窗口
  父窗口 handleMessage（校验 origin + source）
  ├─ sessionToken → POST /auth/v1/bind-session → 后端写 sid/sid_r/k_<HMAC(uid)> cookie，返回 {user, accountKey=uid}
  └─ accountKey(=uid) → authStore.addSavedAccount(user, accountKey) → 存 localStorage
  emit('login-success') → 弹窗关闭，应用刷新状态
```

### 切换流程

```
用户点账号卡片 → onSwitchAccount(acct)
  authStore.switchAccount(acct.accountKey)
    → POST /auth/v1/switch-account {accountKey=uid}
    → 后端 accountKeyForUid(uid) = HMAC(uid) 派生 cookie 名 → request.cookies[cookieName] 读 refreshToken
      ├─ 读到 → refreshSessionCore 轮转 → 下发新 sid/sid_r + 更新该 cookie 的 rt
      │         返回 {action:'switched', user}
      └─ 读不到（非记住我/已撤销/过期）→ 返回 {action:'need_password'}
    ├─ switched → setLoggedIn(user) + fetchPermissions() → emit login-success → 关弹窗
    └─ need_password → 删 localStorage 该项 → 列表空则切到 iframe 登录
```

### 忘掉账号

```
点账号卡片 × → onRevoke(acct)
  authStore.revokeSavedAccount(acct.accountKey)
    → POST /auth/v1/saved-accounts/revoke {accountKey=uid}
    → 后端 accountKeyForUid(uid) 派生 cookie 名 → 读 cookie[cookieName] 的 rt → revokeRememberMe + 清该 cookie + 清 sid_r
  删 localStorage 该项 → 列表空则切到 iframe 登录
```

### 4.2 `src/api/auth.ts` — 免切相关 API

```ts
import service from '@/utils/request'; // 应用自己的 axios 实例（带 credentials + 401 刷新）

export const authApi = {
  /** 绑定 Session（iframe 登录场景，用 session_token 换取 sid/sid_r + 凭证 cookie） */
  bindSession: (sessionToken: string) =>
    service.post('/auth/v1/bind-session', { session_token: sessionToken }),

  /** 免密切换账号（发 accountKey=uid，后端用 HMAC(uid) 派生 HttpOnly cookie 名读 refreshToken） */
  switchAccount: (accountKey: string) => service.post('/auth/v1/switch-account', { accountKey }),

  /** 彻底撤销某账号记住我凭证（"忘掉该账号"，发 accountKey=uid） */
  revokeSavedAccount: (accountKey: string) => service.post('/auth/v1/saved-accounts/revoke', { accountKey }),

  /** 绑定 Token（JWT 模式，用 access_token 换取 Cookie） */
  bindToken: (token: string) => service.post('/auth/v1/bind-token', { token })
};
```

> `service`（axios 实例）必须配置 `withCredentials: true`，否则 HttpOnly cookie 不会被浏览器保存/携带。

### 4.3 `src/stores/auth.ts` — savedAccounts 状态片段

把以下片段并入应用的 auth store（posecraft/firewall 的完整 store 都有，这里只列免切相关部分）：

```ts
import { defineStore } from 'pinia';
import { ref } from 'vue';
import { useCache } from '@/composables/useCache';

const cache = useCache('localStorage', 'posecraft_'); // ← 前缀改成本应用

export const useAuthStore = defineStore('auth', () => {
  // ── 已登录账号清单：{[accountKey]: {username, avatar}} ──
  // key=accountKey（= uid 明文，后端用 HMAC(uid) 派生 HttpOnly cookie 名读 refreshToken），不含凭证
  const savedAccounts = ref<Record<string, { username: string; avatar: string }>>({});

  /** 从 localStorage 恢复已登录账号清单 */
  function loadSavedAccounts() {
    const saved = cache.get<any>('saved_accounts');
    if (saved && typeof saved === 'object' && !Array.isArray(saved)) {
      savedAccounts.value = saved;
    }
  }

  /** 持久化已登录账号清单到 localStorage */
  function persistSavedAccounts() {
    cache.set('saved_accounts', savedAccounts.value);
  }

  /** 登录/绑定成功后记录账号到清单（供下次免切） */
  function addSavedAccount(user: any, accountKey: string | null | undefined) {
    if (!accountKey || !user) return;
    savedAccounts.value[accountKey] = {
      username: user.username || user.name || '用户',
      avatar: user.avatar || ''
    };
    persistSavedAccounts();
  }

  /**
   * 免密切换到指定账号（发 accountKey=uid，后端用 HMAC(uid) 派生 cookie 名读 HttpOnly refreshToken 验证轮转）
   * @returns 成功 {ok:true, user}；失败（凭证失效）{ok:false}，自动删 localStorage 项
   */
  async function switchAccount(accountKey: string) {
    try {
      const { authApi } = await import('@/api/auth');
      const res: any = await authApi.switchAccount(accountKey);
      if (res?.user) {
        savedAccounts.value[accountKey] = {
          username: res.user.username || res.user.name || '用户',
          avatar: res.user.avatar || ''
        };
        persistSavedAccounts();
        setLoggedIn(true, res.user); // 应用自己的登录态设置
        await fetchPermissions(); // 应用自己的权限拉取
        return { ok: true, user: res.user };
      }
      // need_password：凭证失效，删该项
      delete savedAccounts.value[accountKey];
      persistSavedAccounts();
      return { ok: false };
    } catch (err) {
      console.warn('🔒 切换账号失败:', err);
      return { ok: false };
    }
  }

  /** 彻底撤销某账号记住我凭证（"忘掉该账号"，发 accountKey=uid） */
  async function revokeSavedAccount(accountKey: string) {
    try {
      const { authApi } = await import('@/api/auth');
      await authApi.revokeSavedAccount(accountKey);
    } catch (err) {
      console.warn('撤销账号凭证失败:', err);
    }
    delete savedAccounts.value[accountKey];
    persistSavedAccounts();
  }

  // 启动时恢复
  loadSavedAccounts();

  return { savedAccounts, addSavedAccount, switchAccount, revokeSavedAccount /* , ...其它 */ };
});
```

<script setup lang="ts">
import { ref, computed, watch, onMounted, onUnmounted } from 'vue';
import { storeToRefs } from 'pinia';
import { X, UserPlus, ArrowLeft } from 'lucide-vue-next';
import { buildSsoLoginUrl, SSO_URL } from '@/config/services';
import { authApi } from '@/api/auth';
import { useAuthStore } from '@/stores/auth';

const props = defineProps({ isOpen: Boolean });
const emit = defineEmits(['close', 'login-success', 'max-sessions']);

const authStore = useAuthStore();
const { savedAccounts } = storeToRefs(authStore);

const loading = ref(true);
const switching = ref(false);
const loginUrl = buildSsoLoginUrl();

/** SSO iframe 的 origin（postMessage 接收侧只信任此 origin，防恶意页面伪造登录消息） */
const ssoOrigin = (() => {
  try {
    return new URL(SSO_URL).origin;
  } catch {
    return SSO_URL;
  }
})();

/** SSO iframe 引用（用于校验 message 来源窗口） */
const iframeRef = ref<HTMLIFrameElement | null>(null);

/** 'accounts'（账号列表）/ 'login'（iframe 登录），二选一 */
const mode = ref<'accounts' | 'login'>('accounts');

/** savedAccounts 对象 → 数组（便于 v-for） */
const accountList = computed(() =>
  Object.entries(savedAccounts.value).map(([accountKey, acct]) => ({ accountKey, ...acct }))
);

/** 弹窗打开时：有账号默认显示列表，无账号直接 iframe 登录 */
watch(
  () => props.isOpen,
  val => {
    if (val) {
      mode.value = accountList.value.length ? 'accounts' : 'login';
      loading.value = true;
      setTimeout(() => {
        loading.value = false;
      }, 1500);
    }
  }
);

function close() {
  emit('close');
}

/** 点击账号卡片免密切换 */
async function onSwitchAccount(acct: { accountKey: string }) {
  if (!acct.accountKey) return;
  switching.value = true;
  try {
    const result = await authStore.switchAccount(acct.accountKey);
    if (result.ok) {
      emit('login-success', { user: result.user, switched: true });
      close();
    }
    // 失败（凭证失效）：authStore 已删该项；无账号则切到 iframe 登录
    if (!accountList.value.length) mode.value = 'login';
  } finally {
    switching.value = false;
  }
}

/** 点击 × 忘掉该账号 */
async function onRevoke(acct: { accountKey: string }) {
  if (!acct.accountKey) return;
  await authStore.revokeSavedAccount(acct.accountKey);
  if (!accountList.value.length) mode.value = 'login';
}

/**
 * 处理 iframe postMessage：登录成功 → 换 cookie → 通知父级；设备超限 → 冒泡
 *
 * 安全校验：只接受来自 SSO iframe（origin 匹配 + source 匹配）的消息。
 * 否则恶意页面/第三方 iframe 可伪造 { type:'LOGIN_SUCCESS', sessionToken } 注入
 * 攻击者账号的 session_token，让本应用在自身域上绑定攻击者会话。
 */
const handleMessage = async (event: MessageEvent) => {
  // 1. origin 必须是 SSO 登录服务的 origin
  if (event.origin !== ssoOrigin) return;
  // 2. source 必须是当前 SSO iframe 窗口（排除其他 iframe 或父窗口冒泡）
  if (!iframeRef.value || event.source !== iframeRef.value.contentWindow) return;

  if (event.data && event.data.type === 'LOGIN_SUCCESS') {
    const { token, sessionToken, user } = event.data;

    let accountKey: string | null = null;

    // Session 模式：用临时 session_token 换取 sid/sid_r + 凭证 cookie（记住我才有）
    if (sessionToken) {
      try {
        const res: any = await authApi.bindSession(sessionToken);
        accountKey = res?.accountKey || null;
      } catch (err) {
        console.warn('绑定 Session 失败:', err);
      }
    }

    // JWT 模式：用 access_token 换取 Cookie
    if (token) {
      try {
        await authApi.bindToken(token);
      } catch (err) {
        console.warn('绑定 Token 失败:', err);
      }
    }

    // 记录到已登录账号清单（accountKey=uid 存 localStorage 作 key；临时登录 accountKey=null 不记录）
    if (accountKey) {
      authStore.addSavedAccount(user, accountKey);
    }

    emit('login-success', { user, token });
    close();
  }

  // 设备数量超限
  if (event.data && event.data.type === 'MAX_SESSIONS') {
    emit('max-sessions', {
      sessions: event.data.sessions,
      maxSessions: event.data.maxSessions
    });
    close();
  }
};

onMounted(() => {
  window.addEventListener('message', handleMessage);
});

onUnmounted(() => {
  window.removeEventListener('message', handleMessage);
});
</script>

4. **axios 配置**：确保 `withCredentials: true`（HttpOnly cookie 跨域必需），CORS 后端已开 `CORS_ORIGINS`。
5. **App.vue 挂载**：全局放一个 `<LoginModal>`，未登录触发 `showLogin = true`。
6. **oauth21 登录页**：本应用**不需要**改 oauth21 登录页——oauth21 只负责登录，登录成功 `postMessage({type:'LOGIN_SUCCESS', sessionToken, user})` 即可（oauth21 三个登录页已统一为该消息类型）。

## 6. 安全要点

| 风险 | 防护 |
| --- | --- |
| XSS 窃取长期凭证 | refreshToken 全程在 HttpOnly cookie（`k_<HMAC(uid)>`），JS 读不到；localStorage 不存任何凭证 |
| 明文 uid 暴露 | uid 是公开身份标识（= JWT sub），非凭证；cookie 名用 HMAC(uid) 与 accountKey 分离 |
| 伪造 LOGIN_SUCCESS 注入会话 | `handleMessage` 双校验：① `event.origin === SSO origin` ② `event.source === iframeRef.contentWindow` |
| 跨域 cookie 不携带 | axios `withCredentials: true` + 后端 CORS `CORS_ORIGINS` 白名单 + `sameSite=lax` |
| 重复登录产生多条 | accountKey=uid 确定性，localStorage 以 uid 为 key 天然去重 |
| 凭证泄露轮换 | 换 `SESSION_SECRET` → HMAC(uid) 变 → 旧 cookie 名读不到 → 全部强制重新登录 |
| sid_r 长期暴露 | sid_r cookie `path=/auth/v1/refresh-session` 收窄 + `sameSite=strict`，仅刷新端点携带 |
| 切账号轮转后旧 rt 被重放 | 后端 `refreshSessionCore` 标记旧 rt `rotated` 失效 + family 盗用检测 |

## 7. 验证 checklist

- [ ] **未登录点头像** → 弹窗打开，无 savedAccounts → 直接 iframe 登录
- [ ] **登录成功（勾记住我）** → 弹窗关闭，权限拉取，应用进入登录态
- [ ] **再次打开弹窗** → 显示账号列表（模式 A）
- [ ] **点账号卡片** → 免密切换成功，无需输密码
- [ ] **点 × 忘掉账号** → 该账号从列表消失，HttpOnly cookie 被清
- [ ] **不勾记住我登录** → 下次打开弹窗该账号**不**在列表（临时登录不记录）
- [ ] **关浏览器后重开（勾过记住我）** → 30 天内仍可免切
- [ ] **凭证失效（后端清 session / 换 SECRET）** → 切账号返回 `need_password`，列表项自动删除，回退 iframe 登录
- [ ] **DevTools → Application → Cookies** → `k_<hex>` 是 HttpOnly ✅；localStorage `saved_accounts` 不含 token ✅
- [ ] **跨域伪造 postMessage** → 弹窗不响应（origin/source 校验拦截）

## 8. 消息协议（oauth21 → 父窗口 postMessage）

父窗口（本应用 LoginModal）只处理以下来自 oauth21 iframe 的消息：

| `type` | 字段 | 含义 |
| --- | --- | --- |
| `LOGIN_SUCCESS` | `token?, sessionToken?, user, data` | 登录/切换成功。`sessionToken` 走 bind-session 换 sid/sid_r；`token` 走 bind-token（JWT 模式） |
| `MAX_SESSIONS` | `sessions, maxSessions` | 设备数量超限，引导踢设备 |
| `SSO_DENIED` | `error, description` | 用户拒绝授权确认（应用可选择提示） |
| `SSO_READY` | — | iframe 加载就绪（应用可隐藏 loading） |

> oauth21 登录页开发见 `docs/development/登录流程前端开发模板.md`。
