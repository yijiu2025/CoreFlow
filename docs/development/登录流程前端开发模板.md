# 登录流程前端开发模板

> 供 AI 下次开发新 app 前端时参照。本系统采用 **oauth21 SSO 中心 + 各 app iframe 嵌入 MiniLogin + postMessage relay + bind-session 换 cookie** 的统一登录架构。新 app 接入只需按本文复制 5 个文件 + 改 appName/前缀。

## 1. 架构概览

```
用户点登录 → app 弹 LoginModal（iframe 嵌 oauth21 /mini-login）
          → 用户在 iframe 内登录
          → iframe postMessage('LOGIN_SUCCESS', {token, sessionToken, user})
          → app 收到 → 调 /auth/v1/bind-session（sessionToken 换 sid/sid_r cookie）
                      或 /auth/v1/bind-token（token 换 access_token cookie，JWT 模式）
          → setLoggedIn + fetchPermissions → 弹窗关闭
```

- **Session 模式（默认，`JWT_ENABLED=false`）**：sid cookie（30min/30d）+ sid_r（30d，仅"记住我"下发），HttpOnly，`withCredentials` 自动携带。
- **JWT 模式（`JWT_ENABLED=true`）**：access_token/refresh_token cookie，HttpOnly。
- 两模式对前端透明：都走 `bind-session`/`bind-token` 换 cookie，后续请求带 cookie 即可。

## 3. 登录弹窗标准模板（LoginModal.vue）

```vue
<template>
  <Transition name="modal-fade">
    <div v-if="isOpen" class="fixed inset-0 z-[100] flex items-center justify-center p-4 sm:p-6">
      <div class="absolute inset-0 bg-slate-950/60 backdrop-blur-sm" @click="close"></div>
      <div
        class="relative w-[856px] h-[484px] glass-dark rounded-[2rem] overflow-hidden shadow-2xl border border-white/10 flex flex-col animate-in zoom-in-95 duration-300"
      >
        <button
          @click="close"
          class="absolute top-6 right-6 z-10 p-2 rounded-full bg-white/5 hover:bg-white/10 text-slate-400 hover:text-white transition-all"
        >
          <X class="w-5 h-5" />
        </button>
        <div class="flex-1 w-full relative">
          <iframe :src="loginUrl" class="w-full h-full border-none" allow="payment"></iframe>
          <div v-if="loading" class="absolute inset-0 flex items-center justify-center bg-slate-900/50 backdrop-blur-md">
            <div class="w-12 h-12 border-4 border-cyan-500/30 border-t-cyan-400 rounded-full animate-spin"></div>
          </div>
        </div>
      </div>
    </div>
  </Transition>
</template>

<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue';
import { X } from 'lucide-vue-next';
import { buildSsoLoginUrl } from '@/config/services';
import { authApi } from '@/api/auth';

defineProps({ isOpen: Boolean });
const emit = defineEmits(['close', 'login-success', 'max-sessions']);
const loading = ref(true);
const loginUrl = buildSsoLoginUrl();
function close() { emit('close'); }

const handleMessage = async (event: MessageEvent) => {
  if (event.data?.type === 'LOGIN_SUCCESS') {
    const { token, sessionToken, user } = event.data;
    if (sessionToken) await authApi.bindSession(sessionToken).catch(e => console.warn('bindSession 失败', e));
    if (token) await authApi.bindToken(token).catch(e => console.warn('bindToken 失败', e));
    emit('login-success', { user, token });
    close();
  }
  if (event.data?.type === 'MAX_SESSIONS') {
    emit('max-sessions', { sessions: event.data.sessions, maxSessions: event.data.maxSessions });
    close();
  }
};

onMounted(() => {
  window.addEventListener('message', handleMessage);
  setTimeout(() => (loading.value = false), 1500);
});
onUnmounted(() => window.removeEventListener('message', handleMessage));
</script>

<style scoped>
.glass-dark { background: rgba(15, 23, 42, 0.8); backdrop-filter: blur(20px); }
.modal-fade-enter-active, .modal-fade-leave-active { transition: opacity 0.3s ease; }
.modal-fade-enter-from, .modal-fade-leave-to { opacity: 0; }
</style>
```

要点：弹窗**只做壳**，不渲染表单（iframe 内的 MiniLogin 自带 UI）；不要加标题栏（冗余）；postMessage 收到后调 `bindSession`/`bindToken` 换 cookie，再 emit。

## 4. postMessage 协议

iframe → 父窗口：

| type | 字段 | 说明 |
|---|---|---|
| `LOGIN_SUCCESS` | `token`(JWT 模式), `sessionToken`(Session 模式), `user` | 登录成功 |
| `MAX_SESSIONS` | `sessions`, `maxSessions` | 设备并发超限 |
| `SSO_DENIED` | — | 用户拒绝授权 |
| `SSO_CLOSE` | — | 用户关闭弹窗 |

## 5. keepLogin/记住我 链路约定

**前端**：登录页加 `keepLogin` 复选框（默认 true），值放进**加密 payload**：

```ts
// 登录页 executeLogin
const loginPayload = { ...values, keepLogin: keepLogin.value, captchaKey, client_id };
// authApi.login 会把 rest（含 keepLogin）RSA 加密后发后端
```

**后端**：`decryptLoginRequest` 解密取 `keepLogin` → `issueDirectTokens({rememberMe: keepLogin})` → `createSession(rememberMe)`：
- `rememberMe=true`：sid 30d + sid_r 30d（关浏览器再开仍登录，sid 过期自动刷新）
- `rememberMe=false`：sid 30min、**无 sid_r**（关浏览器即失效，30min 后 401 需重新登录）

> ⚠️ 复选框值**必须**进 payload 并透传到 `createSession`，否则 `rememberMe` 写死 true → "不勾记住我"也长期登录，UI 成虚假承诺。

## 6. 401 处理约定（request.ts）

刷新优先，失败内联弹窗（不跳页，保留上下文）：

```ts
async function handle401(config) {
  if (!isRefreshing) {
    isRefreshing = true;
    try {
      const newToken = await authApi.refreshToken(); // POST /auth/v1/refresh-session
      pendingQueue.forEach(cb => cb(newToken)); pendingQueue = [];
      return apiClient(config); // 重放原请求
    } catch {
      const authStore = useAuthStore();
      authStore.logout();
      authStore.openLoginModal(); // 内联弹窗，不 window.location.href
    } finally { isRefreshing = false; }
  }
  return new Promise(resolve => pendingQueue.push(t => { config.headers.Authorization = `Bearer ${t}`; resolve(apiClient(config)); }));
}
```

并发 401 只发一次 refresh，其余排队；刷新失败 → `openLoginModal()`（firewall/posecraft 模式）。

## 8. config/services.ts 模板

```ts
export const API_BASE_URL = import.meta.env.VITE_API_URL || (import.meta.env.DEV ? 'http://localhost:3000' : '');
export const SSO_URL = import.meta.env.VITE_SSO_URL || 'http://localhost:5174';
export const SSO_LOGIN_PATH = '/mini-login';
export const SSO_LOGIN_PARAMS = {
  lang: 'zh_cn', appName: '<本应用>', appEntrance: 'web', styleType: 'horizontal',
  biz_params: '', notLoadSsoView: 'false', notKeepLogin: 'false', isMobile: 'false', qrCodeFirst: 'false', site: '01'
};
export function buildSsoLoginUrl() {
  const params = new URLSearchParams({ ...SSO_LOGIN_PARAMS, rnd: Math.random().toString() });
  return `${SSO_URL}${SSO_LOGIN_PATH}?${params}`;
}
```

## 9. api/auth.ts 模板

```ts
import service from '@/utils/request';
export const authApi = {
  getUserInfo: () => service.get('/user/v1/userinfo'),
  getPermissions: () => service.get('/user/v1/permissions'),
  refreshToken: () => service.post('/auth/v1/refresh-session'),
  bindSession: (sessionToken: string) => service.post('/auth/v1/bind-session', { session_token: sessionToken }),
  bindToken: (token: string) => service.post('/auth/v1/bind-token', null, { headers: { Authorization: `Bearer ${token}` } }),
  updateRememberMe: (rememberMe: boolean) => service.post('/auth/v1/update-remember-me', { rememberMe }),
  logout: () => service.post('/oauth21/v1/auth/logout')
};
```

## 10. 抖音式免切（可选接入）

多账号免密切换在各应用的登录弹窗（LoginModal）内完成，oauth21 登录页只负责登录本身。

- 账号清单存前端 localStorage，key = `accountKey`（后端 `bind-session` 响应返回，= uid 明文，身份标识非凭证）。
- 真正的免切凭据是 HttpOnly cookie（cookie 名 = `HMAC(uid, SESSION_SECRET)`，JS 读不到，后端用 accountKey 派生），localStorage 只存 `accountKey`(=uid) + name/avatar。

```ts
// src/api/auth.ts
switchAccount: (accountKey: string) => service.post('/auth/v1/switch-account', { accountKey }), // accountKey=uid；成功 {user}；失效 {action:'need_password'}
revokeSavedAccount: (accountKey: string) => service.post('/auth/v1/saved-accounts/revoke', { accountKey });
```

登录弹窗：有账号 → 渲染账号卡片（`accountList` from `savedAccounts`）；点击 → `switchAccount(accountKey)`，成功 `setLoggedIn`，`need_password` 删该项并回退 iframe 登录。详见 [session-api.service.js](../../src/framework/auth/session-api.service.js) 的 `switchAccount`/`removeSavedAccount`。
