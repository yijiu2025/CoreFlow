## 日志矩阵 API 重构

- logger.js 将 always/dev/prod 从固定 info 级方法改为"变体对象"（可调用=info 快捷 + 携带全部级别方法 + 可继续链式组合），两个正交维度：必输性（默认受控 vs always 绕过全部门控）× 环境（any/dev/prod）
- 新 API：log.always.error/info/warn/debug、log.dev.info/debug、log.prod.error/warn、log.dev.always.*（与 log.always.dev.* 等价，顺序无关，经 getter 缓存实现）
- 语义：always=必输但不改级别；dev/prod=限环境+正常级别门控（LOG_LEVEL 仍生效），生产必见用 log.prod.always.*
- 旧快捷方式 log.always('...')/log.dev(...)/log.prod(...) 全兼容（现=实例属性可调用对象）
- README 重写为输出控制矩阵表；冒烟三场景 + 兼容性 + jest 74 tests 全通过
