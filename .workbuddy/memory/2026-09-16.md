## ⚠️ 重大发现：`packages/log` 是**独立的嵌套 git 仓库**

**任何时候改 `packages/log/` 下的文件，都不能在主仓提交** ——
`.gitignore:32` 写着 `packages/log/`，主仓对它零跟踪（`git ls-files packages/log/` = 0）。
`git add packages/log/...` 会报 `paths are ignored`，**静默不生效**。

正确做法：
```bash
cd packages/log
git add -A && git commit
git push origin HEAD     # remote = https://github.com/yijiu2025/log.git
```

- `.gitignore:31` 的注释已说明「wb-log 已独立成库，经 npm workspace 软链使用」
- 这个独立仓库**没有**本机 ref 失灵问题，push 后 ref 正常
- 对照：`packages/shared-device` **不是**独立仓库，由主仓跟踪
- 后果教训：我改了 `packages/log/README.md` 后在主仓 commit，
  报的是 gitignore 警告，**Exit Code 仍是 0**，差点当成提交成功。
  → **看到 add 阶段的 gitignore 警告必须停下来查，不能只看退出码！**
