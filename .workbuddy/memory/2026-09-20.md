## E3/E3b 重建完成 + 三次「src 全删」灾难处置

- **删除元凶已锁定**：三次 src/ 大规模删除（116/404/404 文件）**全部紧跟 `git rm` 之后**，监视器
  （`.tmp-probe/watch-src.mjs`，日志 `.tmp-probe/watch.log`）抓到删除期间常驻的 git.exe 进程，
  文件数 404→0 每 2s 掉约 50，历时 ~12s。未用 git rm 的操作（checkout 恢复、Edit、Write）从未触发。
  **规避手段：一律用 POSIX `rm` + `git add -A`，不要 `git rm`**。根因（husky? IDE 同步?）未定，
  监视器可复用。
- **恢复手法（可复用）**：`git status --porcelain -z | tr '\0' '\n' | grep "^ D " | cut -c4- | xargs -d '\n' git checkout --`
  （-z 必须，中文路径 porcelain 会转义；只恢复工作区删除，不动暂存区/未提交修改）。
- **检查点提交策略奏效**：a7c2752 → fb2693b → 60367c1 → 959cf1b，每次做完一批立刻 commit。
