## oauth-web：CI 首跑失败修复（别名双形态，10-15 晚）

- **现象**：CI 首跑（e4aa925）vitest 两 suite 27 例全红：`Failed to resolve import "skinsuite"`——`config/aliases.ts` 把 skinsuite/stable-deviceid 指向 `../packages/*/src/index.ts`，**独立仓 checkout 没有 packages/**；🔴 vite alias 精确匹配优先、**不回落 node_modules**（type-check 却绿：TS paths 未命中会继续 node_modules 解析——alias 与 paths 行为不同）。
- **修法**：`config/aliases.ts` 改**条件注册**（existsSync 门）：源码在→源码直供（monorepo 开发态不变）；不在→**删键**，裸说明符自然解析 node_modules npm 版。npm 版导出集合与源码实测零缺口（skinsuite 31 个全对应；stable-deviceid npm 版只多不少）。
