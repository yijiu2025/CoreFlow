### 坑（当日新增）

- 🔴 **GitHub API：合并 PR 是 `PUT /pulls/<n>/merge`，不是 POST**（POST 静默 404，曾误判为 blocked/权限）；改必检项是 **PATCH** `/branches/main/protection/required_status_checks`（PUT 无效且不报错）。
- 🔴 **CI 作业名一改，分支保护必检项必须同步**，否则 PR 永远 `mergeable_state: blocked`（ reusable workflow 的作业名 = `<caller job key> / <called job name>`，如 `quality / 类型 / 规范 / 单测 / 构建`）。
- 本机 `npm ci`（retroweb）被 safe-delete 垫拦（要删 node_modules/.bin 111 文件 > 50 阈值）；确认 node_modules 与 lock 同步（仅 version bump）后可先用现有依赖预验证，npm ci 未造成损坏（垫拦在删除前）。
- 支线流程自动化：`.tmp-probe/pr-flow.mjs`（建 PR→轮询 checks→全绿 PUT 合并→删支线；token 走 git credential fill）。
