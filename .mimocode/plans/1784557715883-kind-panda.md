## 一、项目概述

### 功能需求
- **持仓管理**：添加/编辑/删除持有的股票，记录买入价、数量、买入日期
- **交易记录**：记录每次买入和卖出操作（价格、数量、时间、手续费）
- **盈亏分析**：实时计算持仓盈亏、收益率、最大回撤
- **AI 操作建议**：基于技术指标 + 持仓情况给出买入/持有/卖出建议
- **经验学习**：记录每次交易的思考和复盘，形成交易日志

### 技术选型
- **后端**：Node.js + Fastify + Sequelize（复用现有基础设施）
- **前端**：Vue 3 + Vite + TypeScript（放在 `/stick` 目录）
- **数据源**：手动录入 + 第三方 API（东方财富/新浪财经）获取实时行情
- **AI 分析**：基于技术指标（MA/MACD/RSI）+ 规则引擎给出建议

## 二、数据模型设计

### 模型清单（命名空间：`stick`）

| 模型 | 表名 | 说明 |
|------|------|------|
| `Stock` | `stick_stock` | 股票基础信息（代码、名称、市场） |
| `Position` | `stick_position` | 持仓记录（当前持有的股票） |
| `Trade` | `stick_trade` | 交易记录（买入/卖出明细） |
| `Analysis` | `stick_analysis` | AI 分析结果和建议 |
| `Journal` | `stick_journal` | 交易日志（复盘和经验） |

### 模型关系

```
Stock (1) ──< Position (N)     一只股票可以有多个持仓
Stock (1) ──< Trade (N)        一只股票可以有多笔交易
Position (1) ──< Trade (N)     一个持仓关联多笔交易
Stock (1) ──< Analysis (N)     一只股票可以有多次分析
Stock (1) ──< Journal (N)      一只股票可以有多篇日志
```

### 字段设计

#### Stock（股票基础信息）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| uid | VARCHAR(36) | UUID，对外暴露 |
| code | VARCHAR(10) | 股票代码（如 600519） |
| name | VARCHAR(50) | 股票名称（如 贵州茅台） |
| market | TINYINT | 市场：1=沪市 2=深市 3=港市 4=美股 |
| industry | VARCHAR(50) | 所属行业 |
| delete_version | BIGINT | 软删除 |

#### Position（持仓记录）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| uid | VARCHAR(36) | UUID |
| stock_id | BIGINT FK | 关联股票 |
| user_id | BIGINT FK | 关联用户 |
| quantity | INTEGER | 持有数量 |
| avg_cost | DECIMAL(10,2) | 平均成本价 |
| total_cost | DECIMAL(12,2) | 总投入金额 |
| status | TINYINT | 1=持有 0=已清仓 |
| delete_version | BIGINT | 软删除 |

#### Trade（交易记录）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| uid | VARCHAR(36) | UUID |
| stock_id | BIGINT FK | 关联股票 |
| position_id | BIGINT FK | 关联持仓 |
| user_id | BIGINT FK | 关联用户 |
| type | TINYINT | 1=买入 2=卖出 |
| price | DECIMAL(10,2) | 成交价格 |
| quantity | INTEGER | 成交数量 |
| amount | DECIMAL(12,2) | 成交金额 |
| fee | DECIMAL(10,2) | 手续费 |
| trade_date | DATE | 交易日期 |
| note | TEXT | 备注 |
| delete_version | BIGINT | 软删除 |

#### Analysis（AI 分析结果）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| uid | VARCHAR(36) | UUID |
| stock_id | BIGINT FK | 关联股票 |
| current_price | DECIMAL(10,2) | 分析时价格 |
| ma5 | DECIMAL(10,2) | 5日均线 |
| ma10 | DECIMAL(10,2) | 10日均线 |
| ma20 | DECIMAL(10,2) | 20日均线 |
| macd | DECIMAL(10,4) | MACD 值 |
| rsi | DECIMAL(10,2) | RSI 值 |
| suggestion | TINYINT | 1=强烈买入 2=买入 3=持有 4=卖出 5=强烈卖出 |
| reason | TEXT | 建议理由 |
| confidence | DECIMAL(3,2) | 置信度 (0-1) |
| delete_version | BIGINT | 软删除 |

#### Journal（交易日志）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| uid | VARCHAR(36) | UUID |
| stock_id | BIGINT FK | 关联股票 |
| user_id | BIGINT FK | 关联用户 |
| title | VARCHAR(100) | 日志标题 |
| content | TEXT | 日志内容 |
| mood | TINYINT | 1=乐观 2=中性 3=悲观 |
| lesson | TEXT | 学到的经验 |
| delete_version | BIGINT | 软删除 |

| POST | `/stick/v1/trades` | stick:trade:write | 记录交易 |
| GET | `/stick/v1/analysis/:stockCode` | stick:analysis:read | 获取股票分析 |
| POST | `/stick/v1/analysis/:stockCode` | stick:analysis:write | 触发 AI 分析 |

## 七、关键技术点

### 行情数据获取

使用免费 API 获取实时行情：
- **东方财富 API**：`http://push2.eastmoney.com/api/qt/stock/get`
- **新浪财经 API**：`http://hq.sinajs.cn/list=sh600519`

### 技术指标计算

| 指标 | 计算方式 | 用途 |
|------|----------|------|
| MA | 简单移动平均线 | 趋势判断 |
| MACD | DIF - DEA | 买卖信号 |
| RSI | 相对强弱指标 | 超买超卖 |
| KDJ | 随机指标 | 短期买卖 |

### AI 建议规则

```
综合评分 = MA趋势(30%) + MACD信号(25%) + RSI状态(25%) + 持仓盈亏(20%)

MA趋势：
- 价格 > MA5 > MA20 → 多头排列 (+1)
- 价格 < MA5 < MA20 → 空头排列 (-1)
- 其他 → 0

MACD信号：
- MACD 金叉 → (+1)
- MACD 死叉 → (-1)
- 其他 → 0

RSI状态：
- RSI > 70 → 超买 (-0.5)
- RSI < 30 → 超卖 (+0.5)
- 其他 → 0

持仓盈亏：
- 盈利 > 20% → 考虑止盈 (-0.3)
- 亏损 > 10% → 考虑止损 (-0.5)
- 其他 → 0

最终建议：
- 综合评分 > 0.5 → 强烈买入
- 综合评分 > 0.2 → 买入
- 综合评分 > -0.2 → 持有
- 综合评分 > -0.5 → 卖出
- 综合评分 ≤ -0.5 → 强烈卖出
```
